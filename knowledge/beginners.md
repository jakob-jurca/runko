## Before starting (screening) [Riebe 2015]
- Healthy, no symptoms: can start light-to-moderate running without a medical check.
- See a doctor first if: known heart, lung, metabolic or kidney disease; chest pain, dizziness, fainting or unusual breathlessness on exertion; pregnancy; recent surgery; or inactive with such conditions. The AI asks about this briefly at onboarding and does not proceed with training advice until the runner confirms clearance when a flag is present.
- Stop and seek help during a run: chest pain/pressure, palpitations, dizziness, fainting.

## Injury reality
- Novice runners: ~17.8 injuries per 1000 h running, about 2x recreational runners. [Videbaek 2015] Most come from doing too much too soon, not from shoes.
- Aerobic fitness adapts faster than tendons and bones, so beginners feel ready for more before their bodies are (see methodology.md).

## Walk-run progression (0 -> 30 min continuous, ~9 weeks)
Based on NHS Couch to 5K structure. 3 sessions/week, never on consecutive days. Every session starts with 5 min brisk walk warm-up and ends with 5 min walk.

| Week | Main set (each session) | Total running |
|---|---|---|
| 1 | 8 x (60 s run / 90 s walk) | 8 min |
| 2 | 6 x (90 s run / 2 min walk) | 9 min |
| 3 | 2 x (90 s run / 90 s walk / 3 min run / 3 min walk) | 9 min |
| 4 | 3 min run, 90 s walk, 5 min run, 2.5 min walk, 3 min run, 90 s walk, 5 min run | 16 min |
| 5 | S1: 3 x 5 min run / 3 min walk. S2: 2 x 8 min run / 5 min walk. S3: 20 min run | 15-20 min |
| 6 | S1: 5-3-8-3-5 min (run-walk-run-walk-run). S2: 2 x 10 min run / 3 min walk. S3: 25 min run | 18-25 min |
| 7 | 25 min run x 3 | 25 min |
| 8 | 28 min run x 3 | 28 min |
| 9 | 30 min run x 3 | 30 min |

Progression rules:
- Advance only if the previous week felt manageable (RPE ≤ 5 on runs, no pain > 2/10 next morning).
- Repeat a week as often as needed. Repeating is normal; many need 10-14 weeks.
- Unfit, older (> 50-60), or high body weight: start with 2-4 weeks of brisk walking 30 min 3-5x/week, then walk-run with 30 s run / 90 s walk.
- Week 5 session 3 (first 20 min continuous) is the biggest jump; offer a 2 x 10 min run / 2 min walk alternative.
- Missed 1 week: repeat the last completed week. Missed ≥ 3 weeks: go back 2-3 weeks.

## Realistic timelines (from zero, healthy adult, 3-4 runs/week)
- 30 min continuous / 5K: 8-12 weeks.
- Comfortable 5K + first 10K: 3-6 months total.
- Half marathon: ~6-12 months of consistent running; start a 12-week half plan only when running ≥ 3x/week and ≥ 20-25 km/week, with a long run of ~8-10 km.
- Marathon: recommend ≥ 12-18 months of consistent running and a completed half first; start a marathon plan only with a base of ≥ 30-40 km/week (coaching consensus; Daniels, Pfitzinger and Hansons plans all assume existing base).
- First weeks after 30 min: build to 3-4 runs/week, 20-30 min each, before increasing length.
- Speed: expect noticeable improvement in pace within 2-3 months without any speedwork.

## Pace: how to know it is right
- Talk test: can speak in full sentences but cannot sing. If only a few words at a time -> too fast. Talk test accurately tracks the first ventilatory threshold (Zone 1 boundary). [Persinger 2004; Foster 2008]
- RPE 3-4/10 ("easy, could keep going").
- Heart rate (optional): ~65-79% HRmax. HRmax formulas are ±10-12 bpm inaccurate for individuals; use `208 - 0.7 x age` over `220 - age`. [Tanaka 2001] Effort and talk test overrule HR formulas.
- Beginners' easy pace is often close to brisk walking pace. Slow jogging (even ~8:00-9:00 min/km) is correct if it passes the talk test.
- If breathing forces a stop: slow down or add walk breaks. Walking is not failing.
- Hills: walk steep uphills.

## Common beginner mistakes (and the fix)
1. Running every run too fast -> talk test, slow down, walk breaks.
2. Increasing too fast after feeling good -> follow the plan; single run ≤ 10% longer than longest in last 30 days (methodology.md).
3. Running on consecutive days early -> rest day between runs for the first 8-12 weeks.
4. Ignoring pain -> apply pain rule in injuries.md; 3+/10 pain that lingers = reduce.
5. Doing speedwork too early -> no intervals in first ~3 months; strides after ~4 weeks continuous running are fine.
6. Comparing to others / apps / friends -> compare to own last week.
7. Wrong shoes -> choose a comfortable running shoe fitted in a running shop; comfort is the best selection criterion; avoid sudden switch to minimalist shoes.
8. Overstriding / heel slamming -> slightly shorter, quicker steps; +5-10% cadence reduces hip and knee loading. [Heiderscheit 2011] Do not force 180 steps/min.
9. Skipping warm-up -> start every run with 5 min walk or very slow jog.
10. Inconsistency -> 3 short runs/week beat 1 long one.
11. Not eating/drinking enough around runs -> see nutrition.md basics.

## Beginner-specific coaching rules for the AI
- Frequency before duration before intensity.
- Goal is consistency and enjoyment in the first 3 months; no race pace talk until 30 min continuous is comfortable.
- Soreness (DOMS) 24-72 h after first runs is normal and fades; sharp or one-sided pain is not.
- Stitches (side pain): slow down, deep exhalation, avoid large meals < 2 h before.
- Strength: 2x/week 15-20 min bodyweight (squats, lunges, calf raises, glute bridges, planks) reduces injury risk.
- Weight loss goals: running supports health; the AI does not set weight or calorie targets (see nutrition.md safety rules).

## Scenario: complete_beginner
Who: never runs, or only rarely; cannot yet run 20 minutes without stopping. May have a distance in mind (e.g. "5 km comfortably") but no date.
How the plan is built (the app enforces these; explain them, never contradict them):
- Prescribed in MINUTES, not kilometres. Each session: 5 min brisk walk, a walk-run main set, 5 min walk.
- 3 sessions a week, never on consecutive days. The rest day is when the body adapts.
- Walk-run ladder (NHS Couch to 5K shape): 1 min run / 90 s walk first, bouts lengthen weekly until 20 min non-stop (~week 8). Over 55 or walking-only: start at 30 s run / 90 s walk (~week 10).
- Weekly running time grows at most +10 running minutes a week (or 10%, whichever is less); no session runs more than 10% or 5 min longer than the longest recent one. BMI 30+: walk briskly first (3 weeks at BMI 30-34.9, 6 at 35-39.9), no intensity for 26 weeks, 3 runs a week; BMI 40+ gets a walking plan until a clinician agrees.
- No tempo, intervals or hills. Speed comes for free in the first months.
- The plan ends when the long session reaches the goal: 30 min continuous, or ~5 km non-stop.
How to talk to them:
- Walking is part of the plan, not failure. Repeating a week is normal and smart.
- Pace = talk test: full sentences. Slow jogging at 8-9 min/km is correct.
- Soreness 1-2 days after is normal; sharp or one-sided pain is not: stop and rest.
- Celebrate showing up. Consistency, not speed, is the whole goal of these weeks.

## Scenario: beginner_with_deadline
Who: little or no running experience AND an event sooner than a comfortable build allows. The most dangerous case: heart and lungs adapt in weeks, tendons and bones need months, so eager beginners feel ready before they are.
How the plan is built (the app enforces these; explain them, never contradict them):
- Goal = finish safely. Pace is irrelevant; no target time is set.
- If they do not run yet: the walk-run ladder, as far as the date allows. If they run a little: easy kilometres with a gently growing long run (+1 km or 10% a week).
- No speed work at all. Every run easy.
- Walk breaks in the event are planned, not a fallback: e.g. run 4-5 min, walk 1 min from the start, before fatigue forces it.
- If the goal is unsafe (e.g. zero to half marathon in 5 weeks), the app builds the plan for the closest safe goal: a shorter distance on the same date, or the same distance later (half from zero: ~6-9 months).
How to talk to them:
- Honest and warm: the original goal is great, the timeline is the problem.
- Race day: start slower than feels necessary, walk every aid station; finishing upright and wanting more is the win.
- Any pain above 3/10 that changes their stride: stop, walk, and skip the next run.
